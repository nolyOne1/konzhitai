# 云令设计系统

## 产品方向

- 类型：多服务器脚本调度与运维控制台。
- 风格：专业、克制、高信息密度；不用玻璃拟态、营销页结构或装饰性动效。
- 主题：深绿色侧栏、浅色数据工作区、绿色表示健康与主操作、琥珀色表示等待、红色表示故障。

## 核心令牌

| 用途 | 值 |
|---|---|
| 侧栏 | `#10241c` |
| 侧栏激活 | `#1c3b2e` |
| 主背景 | `#f3f5f6` |
| 面板 | `#ffffff` |
| 正文 | `#18211d` |
| 次要文字 | `#66736d` |
| 边界 | `#dfe6e2` |
| 健康/主操作 | `#188457` |
| 等待 | `#ad650f` |
| 故障 | `#b54848` |

字体使用 `Microsoft YaHei`、`PingFang SC`、系统无衬线字体；正文不小于 14px。间距采用 4px 基线，面板圆角 12px，阴影只用于应用外壳和浮层。

## 交互约束

- 所有可点击目标至少 44×44px，并显示明确的悬停与键盘焦点状态。
- 状态不能只依赖颜色，必须同时显示中文文本或形状。
- 页面在 375、768、1024、1440px 宽度下无横向滚动。
- 动效控制在 150–250ms，并遵守 `prefers-reduced-motion`。
- 导航使用语义化 `nav` 与链接，按钮使用原生 `button`。
- 不使用 Emoji 充当图标；图标统一采用 Lucide 或简单几何标记。
